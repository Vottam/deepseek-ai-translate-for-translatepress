# PARSER_AND_POSTPROCESSING.md

## Parsers Corrigidos

### DeepSeekApiHelper::parseTranslatedItems()
- Antes: regex `/^\s*(\d+)\.\s*(.+?)\s*$/` — só matcha com \n
- Depois: split por `---` → fallback newlines → sanitização defensiva

### OpenAITranslationEngine::parse_translated_items()
- Antes: split por newlines, sem sanitização
- Depois: JSON array → `---` delimiter → newlines com sanitização

### Sanitização Defensiva
`preg_replace('/^\s*\d+\.\s+/', '', $item)`
- Remove "1. " "2. " etc. do início de cada item
- Aplica-se tanto a single quanto batch
- Preserva numeração legítima quando original já tem lista
